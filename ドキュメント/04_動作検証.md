# 04_動作検証

03_実装手順.md で作られたアプリの検証項目。正常系・異常系を含む。実装完了後、このチェックリストに沿って確認し、「結果」欄に記入する。

## テスト環境

- [ ] PCブラウザ（Chrome / Edge 最新）で `http://localhost:8000`（ローカル）を確認
- [ ] スマホブラウザ（iOS Safari または Android Chrome）で、自宅Wi-Fi接続時を確認
- [ ] スマホブラウザで、自宅Wi-Fi以外（4G/5G等）接続時を確認（GitHub Pages公開後）
- [ ] 使用データ: `参考/202607.csv`（三井住友）, `参考/A202606.csv`（AMEX）

結果は `OK` / `NG` / `未実施` を記入する。
